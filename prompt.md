На /courier-dashboard кнопки "Выехал", "Прибыл", "Возврат" вообще не реагируют 
на клик — ни визуально, ни в консоли, ни в базе ничего не происходит.

Проверь:
1. Есть ли 'use client' в самом верху файла app/(courier)/courier-dashboard/page.tsx — 
   без этой директивы кнопки не будут интерактивны, это частая причина полной 
   нереагирующей верстки в Next.js App Router
2. Действительно ли на кнопках есть onClick={() => setStage(order.id, 'departed')} 
   и подобные — а не просто верстка без обработчиков (могло потеряться при 
   последних правках когда чинили localStorage/Context)
3. Нет ли поверх кнопок невидимого элемента который перехватывает клики 
   (например обертка с z-index или overlay) — проверь через DevTools 
   Elements, наведи на кнопку "Выехал" и посмотри что реально подсвечивается 
   при наведении, тот ли это элемент

Добавь временно onClick={() => { console.log('клик по Выехал'); setStage(order.id, 'departed') }} 
на одну кнопку, чтобы проверить срабатывает ли обработчик вообще, независимо 
от того сработает ли сам supabase update.
